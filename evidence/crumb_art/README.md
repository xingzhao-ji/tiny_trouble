# Chapter 1 art check

`scripts/chapter/chapter_art.gd` provides the independent `TTChapterArt` library. All assets are original editable Godot geometry using the existing `TTArt` palette and mesh/material helpers. These four PNGs are actual native Godot 4.5.1 studio captures, separate from gameplay and performance evidence.

- `sugar_cube()`: floor-centred; exact normal bounds X/Z ±0.675, Y 0–1.35. Chapter small scale 0.35 and large scale 2 give 0.4725³ and 2.7³. Named `Body`, `CrystalGrains`, `QuietFacets`; 150 eight-triangle crystals share one MultiMesh, with uniform instance scaling and surface-detail shadows disabled. Three render nodes total.
- `paper_tray()`: coordinates are already in chapter space. `Floor` spans X −10.8…−7.4, Z 1.8…4.6, Y 0…0.06. `WallNear`, `WallFar`, and `WallClosed` are 1.0 high and 0.12 thick; the right edge is open. Nominal inside width is 2.68; decorative top rims extend inward 0.004 further. Total dressed bounds X −10.864…−7.4, Y 0…1, Z 1.736…4.664. `PaperFibres` batches 22 quiet floor fibres. No essential text is baked into the geometry.
- `crumb_friends()`: `CrumbL` and `CrumbR` are independent floor pivots at X −0.35/+0.35 and Z +0.045/−0.045. Each exposes `WaveArm/Hand`, `Body`, `EyeL`, `EyeR`, `FootL`, and `FootR`. Animate each `WaveArm.rotation.z` around its authored zero. Combined default bounds are approximately 1.316 × 0.405 × 0.435.
- `paper_pinwheel()`: `Rotor` is at (0, 1.48, 0.02); animate local Z rotation. It contains `Blade0`…`Blade3`, `Hub`, and `Pin`. The static `Stem` and `PaperFoot` remain outside the rotor. Default bounds are 1.16 × 2.06 × 0.345. The four folded paper blades render on both sides.

Run `./tools/Godot.app/Contents/MacOS/Godot --path . --resolution 1920x1080 --script tests/chapter/capture_crumb_art.gd`. Native validation checks actual mesh vertices and MultiMesh transforms; the headless dummy renderer returns identity for MultiMesh transform readback, so this script explicitly requires native rendering. The final run passes 21 checks and saves `art_report.json` and the four studio images. Bounds are validated before captures. Captures were visually inspected for rounded sugar silhouettes, crystal detail, paper folds, pivot placement, and readable faces.
