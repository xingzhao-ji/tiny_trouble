# Tiny Trouble release media drafts

All four full route recordings, encoded-frame checks, raw-file hashes and exact package identity are in `../release_media_027/manifest.json`. MovieMaker uses generated controls at fixed 60FPS; this is not human pacing or real-time performance. Audio is the actual game's original audio, with short fades at trailer cuts; human listening remains pending.

The final capsule backgrounds use a central crop of the native diorama that excludes HUD text. The first drafts had faint HUD labels and remain in `../store_kit_027` as before evidence. Gameplay screenshots are separate and unmodified. Primary dimensions: https://partner.steamgames.com/doc/store/assets/standard
